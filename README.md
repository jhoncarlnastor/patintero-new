# Patintero: Grid Rush

Run: `pip install pygame` then `python main.py`

Controls: WASD / Arrows = move, SHIFT = sprint, SPACE = dash (Mabilis na Runner), P = pause, M = mute, ESC = menu.
Progress (rare coins, owned characters, unlocked maps, best scores) is saved in `savegame.json`. Delete that file to reset.
